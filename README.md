# 给自己一点时间 可玩 Demo

依据《时间贫困游戏 PRD 1.0》制作，价格、日程、计分与门槛沿用第七版；抽卡概率按本次试玩反馈调整。

## 开始试玩

双击本文件夹中的 **启动游戏.cmd**，浏览器会打开游戏。保持启动窗口开启，结束试玩时关闭窗口即可。

你这台电脑已有可用运行环境，不需要另装软件。也可以直接打开 **dist/index.html** 离线试玩，不需要安装依赖。建议用 Chrome 或 Edge；自动存档属于当前浏览器、当前地址。离线页面与本地服务的存档不互通，换端口也不会共享存档。优先固定使用启动程序默认的 4173 端口。

这是本地 Demo，还没有发布到公网。发给朋友时，可把整个 `dist` 文件夹压缩发送，让对方解压后打开 `index.html`；或者后续把 `dist` 发布到静态网站托管，让别人直接打开网址玩。

## 已有玩法

- 完整七天、12类事项、47次免费/付费选择，固定日程可自动推进。
- 每天两次通勤、全天工作、家务均可额外付费。工作早上选择并锁卡，下午只结算一次。
- 普通35%、正合心意38.5%、计划外26.5%。免费普通省1和2分钟各17.5%。
- 初始55元，完成工作日净入账35元。余额不足不能购买，不能预支。
- 延误优先追回；真实时间与体验时间分开。幸福分每天上限100。
- 两条跨天影响：第3天采购好卡→第4天晚饭省5分钟；第5天维修坏卡→第6天复查5分钟。
- 每日锁分，七日总分≥565且至少六天≥60才能通关。
- 自动存档、刷新恢复同一结果、逐项记录、日终计算过程、周结算和JSON导出。

## 美术替换

`dist/assets/scenes/` 存放7张临时矢量场景：commute通勤、office工位、kitchen餐食、home家务/维修/礼物、errands采购/退货、wash洗漱、leisure自由时间。

建议场景横图比例 960×400。直接替换同名 SVG 即可；如果换成 PNG 或 WebP，修改 `dist/js/data.js` 的 `assets` 对应路径即可。不要在图中嵌入游戏数值或按钮。场景可以有多张，按事项细分也可以在同文件中修改每项的 `scene`。

当前美术是可替换的临时素材，部分事项共用场景。尚未加入人物骨骼动画、逐项音效或专门的角色移动控制。

## 文件结构

```text
demo/
  启动游戏.cmd           Windows双击启动
  launch.ps1              启动脚本
  server.cjs              本地静态服务，仅监听本机
  dist/                   可直接游玩/托管的完整网页
    index.html
    styles.css            布局、色彩、动画
    js/data.js            七天日程、价格概率、卡牌文案、素材路径
    js/engine.js          独立数值与状态转换
    js/app.js             界面、交互、自动存档
    assets/scenes/        可替换美术
  tests/engine.test.cjs   数值与流程测试
  tools/build-assets.cjs  生成临时矢量素材（会覆盖同名场景，换美术后勿运行）
```

无第三方依赖，不需要 npm install。安装独立 Node.js 后，也可在此文件夹执行 `node server.cjs`；测试执行 `node --test tests/engine.test.cjs`。正式制作可保留 data/engine 再迁移到 React/TypeScript，不需要重新定义数值。

## 存档与试玩记录

确认方案时，费用、随机结果和钱包一次写入浏览器存储，再播放翻牌。普通刷新不能重抽。记录导出用于回顾和分析，目前不提供导入；清理浏览器数据会删除存档。纯本地Demo不防手动改存档，也没有云存档、登录和排行榜。

幸福分比较使用整数单位，显示四舍五入不影响胜负。模拟胜率只对应指定策略，不承诺每位玩家都有50%胜率。每次修改价格、时间、概率或门槛，应重新验证平衡。
